# tsdown-starter

A starter for creating a TypeScript package.

## Usage

Scaffold a new project from this template without copying its git history:

```bash
pnpx degit https://github.com/blyou/create-tsdown.git my-project
cd my-project
pnpm install
```

## Development

- Install dependencies:

```bash
npm install
```

- Run the unit tests:

```bash
npm run test
```

- Build the library:

```bash
npm run build
```
